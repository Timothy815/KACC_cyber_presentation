The two-year pathway

Two years of connected learning

Year 1

Cybersecurity

Prepares for CompTIA Security+
Protect accounts and data
Investigate threats and vulnerabilities
Explain and defend security decisions
Year 2

Network engineering

Prepares for CompTIA Network+
Configure routers and switches
Build and troubleshoot networks
Connect network design with testing
Programming and tools across both years
Python programming
Students build a foundation in coding and apply it toward network and security automation.
Linux and virtual machines
A working knowledge of Linux, practiced in virtual environments that support experimentation and repeatable labs.
Penetration testing
Authorized instructional labs show how weaknesses are identified and corrected. Technical skills develop alongside professional ethics.
